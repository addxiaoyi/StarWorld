# 1.0 开发与交付核对

已实现三种公共工程、三类真实生活需求及治理界面，配合已有产业、文明、物流、市场和六种救灾响应。冻结 JAR 通过 398 项自动化，源码包与主源码匹配。完整技术和玩法对应见[需求映射](requirements.md)。

## 发布门槛

完整自动化为 398/398，45 个套件；同一 JAR 的九套实服共 185/185 阶段，另有缺依赖双启动与 SQLite 标记恢复。原始日志、实际插件、配置/PREP、主/源码 JAR 和 12 份源码 YAML 已通过证据打包门禁。完整交付包包含源代码、构建工具、配置示例、API/README 和原始证据；交付文件按 CRC、逐项清单和 SHA-256 进行独立核验。各套详情见[测试结果](test-results.md)。

先前候选的通过记录不计入当前冻结版。Folia 按原始要求完成迁移规划并保留明确启用门禁，正式运行仍待上游线程契约及跨区实服；第三国过境、全图道路推断和上游自动生产归因按[边界](roadmap.md)处理。
