# 后续版本计划与验收边界

本计划按原始六系统逐版深化。每一行状态只引用该版本的验证材料，历史JAR的通过记录不会转用于新版本。

当前开发范围截至 **1.4.0**，0.1–1.4功能及本轮发行验收均已完成。新设备通过475项Java、73项Python、20项Node测试，当前产物 `8e7da917…` 的217阶段真实Paper玩法/迁移及独立安装双启动通过，证据与发行ZIP已校验。结果统一见[测试记录](test-results.md)，复验入口见[交接说明](handoff-1.4.0.md)。开发分支为 `codex/complete-development-stages`，交付通过[草稿PR #2](https://github.com/addxiaoyi/StarWorld/pull/2)审阅。

每版按其改动执行有意义的自动化与实服测试，保留失败/中断记录，先固定源码和 JAR 再运行实服。第三国过境、自动上游生产归因、Folia运行和全图道路识别仍需相应公开契约；这些能力不会通过绕过核心权威或开启不安全调度来“完成”。Folia按原始任务保持迁移规划，正式兼容声明须另有上游契约和跨区实服证据。
