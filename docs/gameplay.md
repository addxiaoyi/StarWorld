# 第一阶段游玩验收

1. `/sw status` 检查真实核心连接和每项可选依赖降级，普通玩家不能 event/resolve。
2. 用核心真实命令建立国家、城市和两层领地。无城市领地/无国家领地/非管理身份登记均失败。
3. 登记农场、林场、工坊，先农场积粮，工业消耗面包开工。UUID 顺序可能使下游延后一周期。
4. 库存应表现完整粮食/木业/军工投入，取出的箭可以射击。单独高炉不产武器。
5. 存取普通物品，拒绝改名/附魔/PDC/受损的特殊原版道具。背包满应取消取出并退回扣减，不落地物品。
6. 六地形农业倍数：山脉0.5/河流1.5/平原1.3/森林0.9/沙漠0.3/雪原0.4。森林林木恢复快，山地矿多，矿藏不自然再生。
7. 国家创始人选择工业文明，全国工坊增强、农业减弱，转型冷却六周期。市长无全国转型权。
8. 管理员触发三类事件，库存与 GUI反映倍率，active/aftermath 分段，重启恢复。
9. 破坏锚点/卸载区块/取消认领/城市转国或解散均停产、不扣维护；注销不重置矿藏。原归属重新认领且锚点有效则恢复。
10. 升级真实消耗木板和铁锭，提高产量/原料/维护；注销不退款。
11. 同周期重启不重复产出，停机不补发遗漏周期。检查最后报告和数据库账本。
12. GUI底栏/Shift/双击/拖动都不能拿展示物品或触发登记；换城后不打开旧城面板；进行中凭据禁止 resolve。

测试新存档可将 period-seconds 设10–30加快观察，生产默认300。不要修改既有生产存档周期来测试。
